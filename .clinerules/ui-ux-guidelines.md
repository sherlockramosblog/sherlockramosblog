## Brief overview
Este conjunto de diretrizes é global e abrange princípios de design de UI/UX para desenvolvimento de software, com foco em criar experiências intuitivas, acessíveis e otimizadas para o usuário.

## Visual Design
- Estabelecer uma hierarquia visual clara para guiar a atenção do usuário.
- Escolher uma paleta de cores coesa que reflita a marca, consultando o usuário para diretrizes específicas.
- Usar tipografia de forma eficaz para legibilidade e ênfase.
- Manter contraste suficiente para legibilidade, seguindo o padrão WCAG 2.1 AA.
- Projetar com um estilo consistente em toda a aplicação.

## Interaction Design
- Criar padrões de navegação intuitivos.
- Utilizar componentes de UI familiares para reduzir a carga cognitiva.
- Fornecer chamadas para ação claras para orientar o comportamento do usuário.
- Implementar design responsivo para compatibilidade entre dispositivos.
- Usar animações com moderação para melhorar a experiência do usuário.

## Accessibility
- Seguir as diretrizes WCAG para acessibilidade na web.
- Usar HTML semântico para melhorar a compatibilidade com leitores de tela.
- Fornecer texto alternativo para imagens e conteúdo não textual.
- Garantir navegabilidade por teclado para todos os elementos interativos.
- Testar com várias tecnologias assistivas.

## Performance Optimization
- Otimizar imagens e ativos para minimizar tempos de carregamento.
- Implementar carregamento tardio para recursos não críticos.
- Usar divisão de código para melhorar o desempenho de carregamento inicial.
- Monitorar e otimizar Core Web Vitals (LCP, FID, CLS).

## User Feedback
- Incorporar mecanismos claros de feedback para ações do usuário.
- Usar indicadores de carregamento para operações assíncronas.
- Fornecer mensagens de erro claras e opções de recuperação.
- Implementar análises para rastrear comportamento e pontos de dor do usuário.

## Information Architecture
- Organizar o conteúdo de forma lógica para facilitar o acesso.
- Usar rotulagem clara e categorização para navegação.
- Implementar funcionalidade de busca eficaz.
- Criar um mapa do site para visualizar a estrutura geral.

## Mobile-First Design
- Projetar primeiro para dispositivos móveis, depois escalar para cima.
- Usar elementos de interface amigáveis ao toque.
- Implementar gestos para ações comuns (deslizar, pinçar para zoom).
- Considerar zonas de polegar para elementos interativos importantes.

## Consistency
- Desenvolver e aderir a um sistema de design.
- Usar terminologia consistente em toda a interface.
- Manter posicionamento consistente de elementos recorrentes.
- Garantir consistência visual em diferentes seções.

## Testing and Iteration
- Conduzir testes A/B para decisões de design críticas.
- Usar mapas de calor e gravações de sessão para analisar comportamento do usuário.
- Coletar e incorporar regularmente feedback do usuário.
- Iterar continuamente nos designs com base em dados e feedback.

## Documentation
- Manter um guia de estilo abrangente.
- Documentar padrões de design e uso de componentes.
- Criar diagramas de fluxo de usuário para interações complexas.
- Manter ativos de design organizados e acessíveis à equipe.

## Responsive Design Techniques
- Usar unidades relativas (%, em, rem) em vez de pixels fixos.
- Implementar CSS Grid e Flexbox para layouts flexíveis.
- Usar breakpoints para ajustar layouts para diferentes tamanhos de tela.
- Priorizar conteúdo para visualizações móveis.
- Testar designs em uma variedade de dispositivos e orientações.
